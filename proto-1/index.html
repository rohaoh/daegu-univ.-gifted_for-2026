Arduino 연결

HC-06을 페어링한 뒤 생성된 COM 포트를 선택하세요.

Arduino에서 한 줄마다 JSON 또는 온도,습도 형식으로 보내면 됩니다.
{"temperature": 24.5, "humidity": 48}또는24.5,48

알림 기준

기본값: 온도 18–28°C, 습도 30–65% · 벗어나면 데스크톱 알림을 표시합니다.

Gemini AI

The Gemini API key is configured in main.js.

AI analysis uses the key bundled in this app.
!This prototype embeds the Gemini key in the desktop app. Anyone who receives the app can extract and use the same key, and may exhaust the project's free quota. Do not publish this build publicly.
