# 오늘부터 ARDUINO(아두이노) 시작함

> **아두이노란?**  
> 사람의 두뇌와 같음. 단, 전자기기는 우리처럼 혼자서 생각하고 행동할 수 없기 때문에 두뇌 역할을 담당하는 아두이노 보드에 지식(프로그램)을 넣어줘야 한다. 이 과정을 프로그래밍이라 하며, 아두이노 통합개발환경(IDE)을 통해 진행할 수 있다.  
  
> **입력센서란?**  
> 인체로 비유하자면 오감과 유사  
ex) 적외선 센서, 초음파 센서, 터치 센서, 기울기 센서, 온습도 센서, 소리감지 센서, 충격감지 센서, 모션인식 센서, CDS 조도 센서

> **출력센서란?**
> 인체로 비유하자면 움직이는 근육과 같음(팔, 다리 등)
ex) DC모터, 서보모터, 스텝모터, LED, 3색 LED모듈, 도트매트릭스 LED, 세븐 세그먼트, LCD 모듈, 스피커

**전기적 특성**  
물도 높은곳에서 낮은곳으로 흐른다  
전류도 높은곳에서 낮은곳으로 흐른다  

| 개념 | 비유 (물) | 단위 | 역할 |
| :---: | :---: | :---: | :---: |
| **전압 (Voltage)** | 물의 높이(수압) | V (볼트) | 전류를 밀어주는 힘 |
| **전류 (Current)** | 물의 양(유량) | A (암페어) | 실제로 흐르는 전기의 양 |
| **저항 (Resistance)** | 파이프의 좁은 정도 | $\Omega$ (옴) | 전기의 흐름을 방해/조절 |  

| 구분 | 직류 (DC) | 교류 (AC) |
| :---: | :---: | :---: |
| **흐름 방향** | 일정하게 한 방향으로 흐름 | 주기적으로 방향이 바뀜 |
| **주요 특징** | 전압이 일정하여 회로에 안전함 | 먼 거리 송전에 유리함 |
| **사용처** | 아두이노, 가전 내부 회로(냉장고 등) | 가정용 콘센트, 발전소 |
| **변환** | - | 교류를 직류로 변환하여 기기에 사용 |

| 구분 | 애노드 (Anode) | 캐소드 (Cathode) |
| :---: | :---: | :---: |
| **전기적 성질** | 양극 (+) | 음극 (-) |
| **전류 흐름** | 전류가 들어오는 곳 | 전류가 나가는 곳 |
| **LED 다리 길이** | 상대적으로 긴 다리 | 상대적으로 짧은 다리 |
| **회로 구성** | 전원(+) 쪽에 연결 | 접지(GND/-) 쪽에 연결 |

저항은 극이 없으므로 방향 상관없이 연결하면 되며, 전선은 전기를 전달하는 도체일 뿐 색상과는 무관. 아래의 표는 저항의 몸통에 있는 색상 띠로 저항의 크기를 구분하기 위한 코드표.
